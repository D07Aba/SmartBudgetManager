# 1. What does the software do?

SmartBudget Manager is an Excel workbook designed to help users organize their personal monthly budget. It allows users to record income and expenses, review totals and monthly balance, and understand spending by category. The Dashboard presents a summary and may include charts and budget warnings, depending on the workbook setup.

# 2. Prerequisites

- A computer with Microsoft Excel (2016, 2019, 2021, or Microsoft 365) or a compatible spreadsheet application.
- The SmartBudget_Manager.xlsx workbook.
- Basic computer skills; basic knowledge of entering data in spreadsheet cells is helpful.

# 3. How to get started

1. Locate the file SmartBudget_Manager.xlsx on your computer.
2. Open the workbook in Excel or a compatible spreadsheet application. If a security notice appears, only enable editing if you trust the file source.
3. Open the Transactions worksheet to enter income or expenses in the appropriate empty row. Complete the relevant fields, such as date, description, category, and amount.
4. Use the Categories worksheet to review the available categories (Food, Transport, Rent, Health, and Education).
5. Open the Dashboard worksheet to review the totals, monthly balance, spending summary, and any available charts or budget warnings.
6. Save your changes. Keep a backup copy and avoid overwriting formulas or headings.

**Note:** Worksheet names, formulas, charts, and budget-warning behavior depend on the supplied workbook. If a result does not update as expected, check that data was entered in the intended cells and that formulas were not changed.
